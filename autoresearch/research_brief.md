# Q-Evolve Research Brief

## Long-term question
在 Self-Evolution 过程中，多维能力状态如何变化？哪些 Hidden Capability Drift 无法通过常规被动观测及时发现？Active Probing 能否在有限成本下识别和定位这些变化？

## Current scope
- 当前阶段：G2-Math Pilot
- 研究链条：Measurement → Identifiability → Adaptive Diagnosis
- Self-Evolution 是动态背景；Hidden Capability Drift 是现象；Active Probing 是诊断方法。
- 第一轮只研究数学内部候选行为维度：concept、derivation、logic、planning。
- 当前不声称已经覆盖 Tool Use，也不声称已经完成连续在线 Drift Monitoring。

## Constraints
- Reference、Discovery、Confirmation 必须互斥。
- 观测以 reference/current 配对结果为主。
- Optimized Static 是强基线；Adaptive 超过 Random 不足以证明自适应优势。
- 未经审查的实验结果不能写成正式科学结论。
